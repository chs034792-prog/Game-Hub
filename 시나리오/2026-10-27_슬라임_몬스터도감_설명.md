# 슬라임 키우기 — 몬스터 도감 한 줄 설명 (초안)

- 작성: 시나리오팀 `gamehub-scenario-writer`
- 상태: **디렉터(`gamehub-scenario-director`) 검토 전 초안**
- 대상: `SlimeGame/index.html`의 `MONSTERS` 표 1~30번 (이 순서가 층 순서)
- 용도: 몬스터 도감 UI에 들어갈 기본 종 설명 한 줄씩. 프로그래밍팀(`gamehub-dev-gameplay`)이 그대로 매핑해 코드에 넣는다.

## 쓸 때 지킨 규칙

- 등급 수식어(강화된/흉포한/심연의/전설의/태고의/멸망의/별을 삼킨)는 코드가 이름 앞에 자동으로 붙이므로, 설명 문장에는 수식어를 넣지 않았다. 기본 종 설명 하나가 모든 등급에 재사용된다.
- 1~8번(들쥐~산적)은 가볍고 귀여운 톤, 9~20번(전갈~마왕)은 위협감을 조금씩 올리는 톤, 21~30번은 더 큰 존재감으로 — 특히 19 리치·25 그림자·29 공허 벌레·30 별의 수호자는 신비롭고 거대한 존재로 적었다.
- 번호·이름은 `index.html` 표와 그대로 맞춰 두었다. 번호만 보고 매핑해도 되게 순서를 바꾸지 않았다.
- 길이는 도감 칸을 고려해 15~25자 선으로 맞췄다(공백 포함, 이모지 제외).

## 디렉터 검토가 필요한 지점

- 전체 30개의 **난이도별 톤 그라데이션**이 디렉터가 생각한 슬라임 키우기 세계관 방향과 맞는지.
- 19 리치·20 마왕처럼 같은 구간(16~20층)에 있지만 요청에서 신비 등급으로 따로 지정된 리치와, 그렇지 않은 마왕 사이의 톤 차이가 적절한지.
- 21~30번(불개미~별의 수호자)처럼 속성 몬스터가 늘어나는 구간에서 서사적 과장이 지나치지 않은지(가벼운 방치형 톤 유지 여부).
- 길이 기준(15~25자)이 실제 도감 UI 칸 폭과 맞는지는 프로그래밍팀·아트팀 확인 필요.
