# 밸런스 (게임제작본부 밸런스팀 `gamehub-balance-designer`)

수치를 바꾸거나 새로 넣을 때, **근거(봇 시뮬레이션 도달 웨이브, DPS·성장 곡선 비교표)** 를 만들어 제안하는 곳.

| 파일 | 내용 |
|---|---|
| `YYYY-MM-DD_게임명_주제.md` | 수치 제안서: 현재 수치 → 제안 수치, 전·후 비교표, 시뮬레이션 방법과 결과, 위험 |
| `sim/` | 분석·시뮬레이션 스크립트 (게임 원본을 복사해 읽기만 한다. 원본은 고치지 않는다) |

- 반영(코드 수정)은 프로그래밍팀 `gamehub-dev-gameplay`가 한다. QA 는 반영 후 동작을 확인한다.
- 기존 도구: `Wall-Defense/tools/balance-bot.js` (보통 67웨이브 기준).
- 대표님 방향: 상위 티어가 하위보다 확실히 세게, 넥서스 영웅 Lv1500 목표, 스킬 해금 레벨은 높게, 수치를 바꾸면 근거를 보인다.
