## 1. 한 줄 콘셉트 · 세계관

**한 줄 콘셉트**: "방치해도 자라지만, 중요한 순간엔 내가 지휘한다" — 자동전투 + 지휘관 개입형 방치 파티 RPG.

**세계관 (오리지널, 한 문단)**: 큰 전쟁이 끝난 뒤 뭍은 작은 섬 여럿으로 흩어졌다. 플레이어는 이름 없는 용병단의 '단장'으로, 떠돌이 용병들을 모아 섬을 하나씩 돌며 잃어버린 거점을 되찾는다. 용병들은 알아서 훈련하고 싸우지만, 결정적인 전투(필살기 발동·보스 도전·진형 편성)는 단장이 직접 지시해야 한다 — 그래서 방치해도 자라고, 손대면 더 잘 큰다.

## 2. 슬라임 키우기와의 차이 (차별점)

가상 테스터 불만 1위(자동전투라 개입 요소 없음, 143명)와 바라는 점 1위(조작·전략 개입, 90명)를 정면으로 겨냥한다.

| 항목 | 슬라임 키우기 (기존) | 방치형 파티 RPG (신규) |
|---|---|---|
| 전투 단위 | 슬라임 1체, 완전 자동 | 용병 3인 파티, 자동 전투 + **직접 발동 필살기** |
| 개입 포인트 | 없음 (강화·장비는 전투 밖) | 필살기 버튼 · 파티 편성 · 보스 도전 타이밍 (전투 중/직전) |
| 성장 축 | 강화 9종 + 환생(soulMult) + 업적 | 용병 레벨 + 무기 강화 + 용병 합류(소환) |
| 수집 요소 | 몬스터 도감 240칸 (처치 기록) | 용병 도감(보유 용병 목록) + 몬스터 도감 |
| 세계관 노출 | 거의 없음 (층수만 올라감) | 섬 단위 스테이지 + 짧은 대사로 세계관 체감 |
| 재화 | 젤리 · 영혼 | 골드(판 내) · 용병표(소환 전용, 결제 없음) |

→ 슬라임은 "완전 방치 + 깊은 성장 곱셈", 신규작은 "방치 + 짧은 개입 + 파티·캐릭터 수집"으로 겹치지 않게 분리한다.

## 3. 핵심 반복 루프

| 단위 | 플레이어가 하는 일 |
|---|---|
| **30초** | 전투 화면을 보다가 쿨다운이 찬 **필살기 버튼을 탭** → 큰 데미지/연출. 적 처치 로그·골드 획득을 확인. |
| **5분** | 스테이지 클리어 → 다음 스테이지 진입 여부 결정, 무기 강화 1~2회, 필요하면 **파티 편성(교체)**, 스태미나 여유가 있으면 **보스 도전** 여부 결정. |
| **하루** | 앱 열면 오프라인 보상 수령 → 출석 보상 → 일일 임무(예: 보스 1회 도전, 강화 3회, 소환 1회) 확인·완료 → 모인 용병표로 소환(가챠) 1~2회. |

## 4. 개입 요소 (방치 중에도 손이 가는 것)

1. **필살기 직접 발동** — 파티 공용 게이지가 차면 버튼이 빛난다. 자동으로도 터지지만(방치 가능), 직접 탭하면 데미지 보너스(예: +20%) 또는 확정 크리티컬을 준다. "내가 눌러서 이겼다"는 체감을 1회 전투 단위로 준다.
2. **파티 편성/진형** — 보유 용병 중 3인을 배치(탱커 앞, 딜러 뒤 등). 다음 스테이지·보스의 속성에 따라 편성을 바꾸는 선택이 생긴다.
3. **보스 도전 타이밍** — 보스전은 스태미나를 쓰는 별도 버튼. "지금 이길 수 있을까"를 판단해 직접 눌러 들어가는 리스크·보상 선택 (넥서스 테스터가 바란 "영웅 해금을 초반에 맛보기"처럼, 보스 첫 승 시 바로 보상 체감).

## 5. 1차 판 범위 (작게 시작)

| 항목 | 넣을 것 (1차) | 나중에 넣을 것 |
|---|---|---|
| 용병 캐릭터 | 6종 (전사·궁수·법사·힐러·도적·탱커 각 1, 희귀도 일반/희귀/영웅 3단계) | 캐릭터 추가, 각성·스킬트리 |
| 스테이지 | 5구역 × 4스테이지 = 20개, 구역당 보스 1체(총 보스 5) | 구역·스테이지 확장, 환생(섬 재도전) |
| 장비·강화 | 무기 1슬롯, 레벨형 단순 강화(수치만 상승) | 방어구·장신구, 세트 효과 |
| 파티 편성 | 3인 고정 슬롯, 보유 용병 중 교체 가능 | 진형별 버프, 5인 파티 |
| 필살기 | 파티 공용 게이지 1개 | 용병별 개별 스킬 |
| 소환(뽑기) | **게임 내 재화(용병표)만 사용, 실제 결제 없음.** 중복 용병은 강화재료로 환전 | 결제 연동(상용화 검토 시 별도 논의), 천장(보장) 시스템 정교화 |
| 수집 | 용병 도감(보유 목록) + 몬스터 도감(처치 기록) | 도감 완성 보상 확장 |
| 재방문 | 오프라인 보상(최대 8시간, 슬라임 테스터 요청대로 여유 있게), 일일 임무 3개, 7일 출석 보상 | 주간 임무, 이벤트 |

**뽑기(소환) 포함 여부는 대표님 결정 필요** (6번 항목 참고).

## 6. 휴대폰 화면 구성 스케치 (세로 화면, 탭 전용)

```
┌─────────────────────────┐
│ [상단바] 레벨 · 골드 · 용병표   │  ← 상태 요약, 고정
├─────────────────────────┤
│                         │
│  [파티 3인 아이콘]  [적 1~3체]  │  ← 전투 영역 (자동 진행)
│        전투 로그 텍스트         │
│                         │
├─────────────────────────┤
│     [필살기 큰 원형 버튼]      │  ← 쿨다운 게이지 테두리, 꽉 차면 빛남
├─────────────────────────┤
│ [파티] [강화] [소환] [임무] [도감] │  ← 하단 탭바 5개, 탭 전용
└─────────────────────────┘
```
- 모든 조작은 탭 1번으로 끝난다 (드래그·스와이프·멀티터치 없음 — 벽짓살이 내려간 이유인 "휴대폰 조작 불일치" 재발 방지).
- 세로 화면 고정, 글자 크기는 슬라임 테스터 불만("숫자·글씨 작음")을 반영해 상단바·버튼 모두 크게.

## 7. 효과음 목록 (Web Audio 직접 생성, 파일 없음)

1. 평타 타격음 (짧은 '퍽')
2. 필살기 발동음 (상승음 + 터지는 음)
3. 크리티컬 음 (높은 '핑')
4. 레벨업/강화 성공음 (상승 아르페지오)
5. 보스 등장음 (낮은 경고음)
6. 전투 승리 팡파레
7. 소환(뽑기) 연출음 (희귀도별로 음 높이 다르게 — 영웅 등장 시 더 화려하게)
8. 버튼 탭음 (공용, 짧은 '틱')

→ 두 게임(넥서스·머니) 테스터가 공통으로 꼽은 "효과음 없음" 불만을 신규작은 처음부터 해결한다.

## 9. 대표님 결정 필요 항목

1. **게임 이름/세계관** — 가칭 "용병단 키우기"로 1차 진행해도 될지, 다른 이름을 원하시는지.
2. **소환(뽑기) 포함 여부** — (A) 1차 판부터 포함(게임 내 재화만, 결제 없음) / (B) 1차는 제외하고 소환 없이 용병을 스테이지 클리어로만 해금, 다음 버전에 추가. **확인 필요.**
3. **1차 판 범위 크기** — 용병 6종·스테이지 20개가 "며칠 안에 만들 수 있는 범위"에 맞는지, 더 줄일지(예: 용병 4종·스테이지 12개) 늘릴지.
4. **저장 키 이름** — 기존 키와 겹치지 않는 새 키로 `gamehub.idlerpg.v1`을 제안합니다. 확정해 주시면 프로그래밍팀에 그대로 전달합니다.
5. **담당자 배정** — 1차 구현(프로그래밍 1명 + QA)을 누가 맡을지는 GameHub 팀장(`gamehub-team-lead`)의 배분이 필요해 이 기획서에는 비워 둡니다 (내부 규칙: 담당자 미정 시 추측하지 않음).
