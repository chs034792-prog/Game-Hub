작성: 기획경영부 게임 기획 담당자 (`game-planner`)
대상: 슬라임 키우기 · 넥서스 디펜스 · 머니 디펜스 · 극한 벽짓고 살아남기 · Game Hub
근거: 각 게임 `README.md`, `교육/프로젝트_교육자료.md`, 허브 `index.html`/`play.html`. 코드는 읽기만 했고 고치지 않았다.

## ① 한 줄 결론

**4개 게임 모두 "하는 동안의 재미"는 탄탄한데, "다시 켜고 싶게 만드는 장치"(일일 보상·임무, 신규 온보딩, 게임 간 연결)가 공통으로 약하다 — 특히 머니 디펜스는 영구 성장(프레스티지) 자체가 없어 격차가 가장 크다.**

## ② 게임별 분석

### 🟢 슬라임 키우기

**이미 잘 된 점**
- 첫 몬스터 5초컷 + 0단계에서도 초당 1 젤리로, 방치해도 완전히 막히지 않는 초반 설계 (README "수치 설계").
- 손맛(스쿼시·크리 연출)과 환생(soulMult)·업적(achMult)·영혼강화 7종으로 장기 성장 곱셈 고리가 풍부.

**부족한 점**
1. **재방문 유인이 오프라인 보상뿐**이다. 일일 접속 보상·로그인 보너스·이벤트가 README 어디에도 없다 (근거: README 전체, "저장/오프라인 보상" 절).
2. **"다음 목표" 상시 노출 UI가 안 보인다.** 다음 무기 해금까지 몇 레벨, 다음 업적까지 뭐가 남았는지를 알려주는 패널이 README에 없다.
3. **수집 요소가 약하다.** 몬스터 30종이 21층부터는 같은 목록에 수식어만 바뀌어 반복된다(README "전투 무대"). 도감·처치 기록 보상이 없다.
4. **선택의 재미(빌드 다양성)가 약하다.** 장비 3칸은 "최고 등급을 사서 끼운다"는 단일 정답에 가깝고, 업그레이드 9종도 전부 선형 누적이라 트레이드오프가 드물다.
5. 큰 수 처리 미비(README "다음에 할 일" 4번) — 후반 숫자가 이해하기 어려워져 장기 유저 피로 요소가 될 수 있다.

**보완 제안**
- 일일 보상(접속 시 젤리/영혼 보너스) — 효과 **상** · 난이도 **중**
- 몬스터 도감(처치 기록 + 완성 보상) — 효과 **중** · 난이도 **중** (대표님이 좋아하는 "콘텐츠 확장" 결)
- 상단에 "다음 목표" 고정 패널(다음 무기 Lv, 다음 업적) — 효과 **상** · 난이도 **하**
- 큰 수 라이브러리 교체 — 효과 **중** · 난이도 **상** (README에 이미 적힌 숙제)

### 🔷 넥서스 디펜스

**이미 잘 된 점**
- 판 내(골드)·영구(코어) 이중 루프, 17개 지역·테크트리 100웨이브 단위 해금으로 "다음 목표"가 항상 보인다.
- 온라인 랭킹·쿠폰·백업코드·무료복권(일일 1장+웨이브 달성)까지 재방문·소셜 장치가 4개 게임 중 가장 충실하다.

**부족한 점**
1. **신규 온보딩이 안 보인다.** 지역 정보·테크트리·영웅 직업·특수강화 등 누를 게 많은데, README에 "처음 켰을 때 안내"가 없다. 복잡한 게임일수록 초반 이탈 위험이 크다 (확인 필요: 실제 게임 내 튜토리얼 존재 여부).
2. **명시적 일일 임무가 없다.** 무료복권은 있지만 "오늘 3판", "웨이브 50 도달" 같은 임무·보상 흐름은 없다.
3. **한 판의 끝이 항상 "전멸"이다.** 2500웨이브(종말의 끝) 이후도 그냥 "죽을 때까지 계속"이라 성취감 있는 마무리 지점이 없다.

**보완 제안**
- 첫 판 전용 안내 툴팁(지역/테크트리/영웅 소개) — 효과 **상** · 난이도 **중**
- 일일 임무(판 수, 웨이브 도달) → 코어/복권 보상 — 효과 **상** · 난이도 **중**
- 종말의 끝 이후 특별 보상/칭호 — 효과 **중** · 난이도 **하**

### 💰 머니 디펜스

**이미 잘 된 점**
- 퀘스트 22개가 이미 중기 목표 역할을 하고 있고, 몹 특성 12주기 변화로 루프가 계속 신선하다.
- 보스 6종 + 황금 돼지로 손맛 포인트가 주기적으로 찍힌다.

**부족한 점**
1. **영구 성장(프레스티지) 재화가 없다.** 슬라임의 환생/영혼, 넥서스의 코어, 벽짓살의 사이오닉 정수에 해당하는 게 README 어디에도 없다 — 판이 끝나면("게임 끝내기") 다음 판은 완전히 처음부터다 (확인 필요: 코드에 숨은 메타 시스템이 있는지).
2. **게임 오버가 없는 "성 지키기"식**이라 끝이 플레이어의 포기뿐이고, 목표 지점이 모호하다.
3. **재방문 장치(일일/주간/오프라인 보상)가 전혀 없다.**
4. 난이도별 자동 플레이 도달 라운드(하수 60 · 중수 44 · 하드코어 30)가 난이도를 올릴수록 빠르게 막혀, 상위 난이도 초반 이탈 가능성이 있다(README "밸런스").

**보완 제안**
- 영구 성장 재화 신설(예: 판 종료 시 처치/라운드 기반 "경영 포인트" → 다음 판 영구 보너스) — 효과 **상** · 난이도 **상** (새 시스템 + 저장 구조 추가)
- 출근 보너스/일일 퀘스트 — 효과 **중** · 난이도 **중**
- 난이도별 최고 기록판(업적) — 효과 **중** · 난이도 **하**

### 🧱 극한 벽짓고 살아남기

**이미 잘 된 점**
- 영구 성장(사이오닉 정수)·업적 27종·보너스 목표·유물 뽑기까지 리텐션 장치가 4개 게임 중 가장 체계적이다.
- 통계 탭과 밸런스 봇으로 수치 투명성이 높다.

**부족한 점**
1. **조작이 가장 복잡하다.** 단축키가 20개 이상(README "조작" 표)이라 신규 유저 러닝커브가 가장 높을 수 있다(확인 필요: 실제 이탈률).
2. 일일/주간 재접속 유인 장치가 README에 없다.
3. **온라인 랭킹이 없다.** 넥서스 디펜스에만 있는 소셜 비교 장치가 빠져 있어, 100웨이브 승리 이후의 "더 잘하고 싶다" 동기가 약하다.

**보완 제안**
- 첫 판 추천 사령관/맵 안내 배너 — 효과 **중** · 난이도 **하**
- 일일 도전(지정 변이원 조합, 보너스 정수) — 효과 **중** · 난이도 **중**
- 온라인 랭킹 추가(넥서스와 같은 방식) — 효과 **상** · 난이도 **상** (Supabase 연동 필요 — 비용/범위 CEO 확인 필요)

### 🎮 Game Hub

**이미 잘 된 점**
- 카드에 각 게임의 핵심 기록(레벨/웨이브/코어 등)이 바로 보여 "이어서 하고 싶다"는 동기를 준다.
- 하단 통합 기록(플레이한 게임 수, 총 출격, 최고 웨이브)으로 게임 간 비교가 가능하다.

**부족한 점**
1. **처음 온 사람이 뭐부터 할지 안내가 없다.** 카드 4장이 동등하게 떠서 선택 마비가 생길 수 있다.
2. **게임 간 연결 보상이 없다.** 한 게임을 많이 한 유저에게 다른 게임을 권할 장치(크로스 프로모션)가 없다.
3. **허브 차원의 수집/업적이 없다.** "4개 게임 모두 플레이" 같은 뱃지가 없어 허브 자체의 완료 욕구를 못 만든다.

**보완 제안**
- 신규 유저 배너("처음이면 슬라임부터 추천") — 효과 **중** · 난이도 **하**
- 허브 공통 뱃지(예: 4개 게임 모두 기록 보유 시 표시) — 효과 **중** · 난이도 **중**
- 크로스 프로모션 문구(예: 한 게임 랭킹 상위권이면 다른 게임 카드에 노출) — 효과 **하** · 난이도 **중**

## ③ 공통으로 부족한 것

- **일일/주간 재방문 장치가 4개 게임 모두 약하거나 없다.** (슬라임: 오프라인 보상만 / 넥서스: 무료복권만 / 머니·벽짓살: 없음)
- **신규 유저 온보딩(튜토리얼)이 README에 명시돼 있지 않다.** 콘텐츠가 가장 많은 넥서스·벽짓살일수록 초반 이탈 위험이 클 것으로 추정된다 (확인 필요).
- **머니 디펜스만 영구 성장(프레스티지) 재화가 없다.** 다른 세 게임과의 격차가 가장 크다.
- **허브 차원에서 게임 간 연결·수집 요소가 없다.** 각 게임이 완전히 독립적으로 존재한다.
